# Lesson 1 练习题（描述统计与分布）

> 数据：`data/wait_times.csv`（候诊时长，含脏数据 + 超长候诊）
> 先自己做，答案在底部折叠区。

## 基础

1. 清洗数据：把「等候时长」转成数字（脏数据变 NaN），打印有效值条数和脏数据条数。
2. 算出均值、中位数、标准差，并说明「均值为什么比中位数高」。
3. 算出 P25 / P50 / P75 和 IQR。
4. 用 IQR 法则找出异常值，列出具体数字。

## 进阶

5. 用 3σ 法则找出异常值，和第 4 题对比：**哪种方法多抓到了哪个值？为什么？**
6. 各科「均值 vs 中位数」对比，哪个科室两者差距最大？说明了什么？
7. 思考：领导问「我们平均候诊多久？」，你只回「30.79 分钟」有什么问题？你会怎么补充？

```python
import pandas as pd
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent
df = pd.read_csv(BASE_DIR / "data" / "wait_times.csv", encoding="utf-8")
df["等候时长"] = pd.to_numeric(df["等候时长"], errors="coerce")
s = df["等候时长"].dropna()

# 1
print(len(s), df["等候时长"].isna().sum())     # 126, 1

# 2
print(s.mean(), s.median(), s.std())           # 30.79, 25.0, 32.15
# 均值被 5 个超长候诊(158~222)拉高，中位数不受影响

# 3
q1, q3 = s.quantile([0.25, 0.75])
print(q1, s.quantile(0.5), q3, q3-q1)          # 19.25, 25.0, 31.0, 11.75

# 4
iqr = q3 - q1
out = s[(s < q1-1.5*iqr) | (s > q3+1.5*iqr)]
print(sorted(out.tolist()))                    # [-5, 158, 164, 179, 181, 222]

# 5
lo, hi = s.mean()-3*s.std(), s.mean()+3*s.std()
out3 = s[(s < lo) | (s > hi)]
print(sorted(out3.tolist()))                   # [158, 164, 179, 181, 222]
# 3σ 漏了 -5：因为 5 个极端值把 std 撑到 32.15，下界被拉到 -65.66，-5 不算异常
# → 数据有极端值时，IQR 比 3σ 更稳健

# 6
print(df.groupby("科室")["等候时长"].agg(["mean","median"]).round(2))
# 内科：均值 32.81，中位数 23.0，差 9.81 最大 → 内科有极端长候诊

# 7
# 只报 30.79 会掩盖「多数人等 25 分钟、少数人等 2-3 小时」的真相。
# 更专业的回答：「中位数约 25 分钟，但标准差 32，存在长候诊（最长 222 分钟），
# 建议单独看 P90 和超长候诊人数。」
```
