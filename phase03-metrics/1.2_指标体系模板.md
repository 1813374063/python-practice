> 使用说明：把每一行的【】替换成你的定义 + 用练习库真实算出的数。
> 目标：10–15 个指标，每个都要能说清口径、能写 SQL 取数。

## 二、逐指标详细口径（每个指标复制这一块填写）

### 指标 1：门诊接诊量

```text
分类：运营量级
指标名：门诊接诊量
口径：
  分子：visits.patient_count 求和
  分母：无
  去重：按 dept_id + visit_month 唯一（表中已是月度汇总）
  时间：按 visit_month 归属月份
  数据源：visits 表
公式：SUM(patient_count) GROUP BY dept_id, visit_month
维度：科室 / 月份
时间粒度：月
当前值：【待填】
```

### 指标 2：工单解决率

```text
分类：效率
指标名：工单解决率
口径：
  分子：status IN ('resolved','closed') 的工单数
  分母：当月新建工单总数
  去重：按 ticket_id 去重
  时间：按 created_at 归属月份
  数据源：tickets 表
公式：COUNT(resolved+closed) / COUNT(*)
维度：整体 / 科室 / 工程师
时间粒度：月
当前值：【待填】
```

### 指标 3：工单平均处理时长

```text
分类：效率
指标名：工单平均处理时长（天）
口径：
  分子：SUM(resolved_at - created_at) 仅 resolved 工单
  分母：resolved 工单数
  去重：按 ticket_id
  时间：按 resolved_at 归属月份
  数据源：tickets 表
公式：AVG(resolved_at - created_at)
维度：整体 / 科室 / 优先级
时间粒度：月
当前值：【待填】
```

> 其余指标同理，每条都要写清 分子/分母/去重/时间/数据源。
