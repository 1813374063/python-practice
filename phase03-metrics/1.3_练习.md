### 练习 1

```sql
SELECT
  ROUND(COUNT(*) FILTER (WHERE status = 'resolved') * 100.0 / COUNT(*), 2) AS 口径A,
  ROUND(COUNT(*) FILTER (WHERE status IN ('resolved','closed')) * 100.0 / COUNT(*), 2) AS 口径B
FROM tickets;
-- 结果：口径A = 48.57%，口径B = 71.43%
```

**1.2**：口径不同差 20+ 个百分点。报表只写「解决率 70%」而不写口径，
别人无法复现、无法对账，甚至被质疑「是不是故意挑好看的数」。**报数必带口径。**

### 练习 2

```sql
-- 2.1
SELECT visit_month, SUM(patient_count) AS 总接诊量
FROM visits
GROUP BY visit_month
ORDER BY visit_month;

-- 2.2
SELECT d.dept_name,
       SUM(v.patient_count) AS 接诊量,
       ROUND(SUM(v.patient_count) * 100.0 / (SELECT SUM(patient_count) FROM visits), 2) AS 占比
FROM visits v
JOIN departments d ON d.dept_id = v.dept_id
GROUP BY d.dept_name
ORDER BY 接诊量 DESC;

-- 2.3
SELECT status, COUNT(*) AS 工单数
FROM tickets
GROUP BY status
ORDER BY 工单数 DESC;

-- 2.4
SELECT ROUND(COUNT(*) FILTER (WHERE priority = 'P1') * 100.0 / COUNT(*), 2) AS p1占比
FROM tickets;

-- 2.5
SELECT d.dept_name, COUNT(t.ticket_id) AS 工单数
FROM departments d
LEFT JOIN tickets t ON t.dept_id = d.dept_id
GROUP BY d.dept_name
ORDER BY 工单数 DESC;
```

### 练习 3

```sql
-- 3.1 加法拆解：每个科室 10月 vs 11月
SELECT d.dept_name,
       SUM(CASE WHEN v.visit_month = '2026-10-01' THEN v.patient_count ELSE 0 END) AS 十月,
       SUM(CASE WHEN v.visit_month = '2026-11-01' THEN v.patient_count ELSE 0 END) AS 十一月,
       SUM(CASE WHEN v.visit_month = '2026-11-01' THEN v.patient_count ELSE 0 END)
         - SUM(CASE WHEN v.visit_month = '2026-10-01' THEN v.patient_count ELSE 0 END) AS 变化
FROM visits v
JOIN departments d ON d.dept_id = v.dept_id
WHERE v.visit_month IN ('2026-10-01','2026-11-01')
GROUP BY d.dept_name
ORDER BY 变化;

-- 3.3 总量环比
SELECT
  SUM(CASE WHEN visit_month = '2026-11-01' THEN patient_count ELSE 0 END) AS 十一月,
  SUM(CASE WHEN visit_month = '2026-10-01' THEN patient_count ELSE 0 END) AS 十月,
  ROUND(
    (SUM(CASE WHEN visit_month = '2026-11-01' THEN patient_count ELSE 0 END)
     - SUM(CASE WHEN visit_month = '2026-10-01' THEN patient_count ELSE 0 END)) * 100.0
    / SUM(CASE WHEN visit_month = '2026-10-01' THEN patient_count ELSE 0 END), 2) AS 环比百分比
FROM visits;
-- 结果：11月 9860，10月 10480，环比 -5.92%
```

**3.2 答案**：内科变化 **-300**，是最大拖累（门诊部 -150、急诊科 -70 次之，药房 +30 是唯一正增长）。
总下降 -620，内科贡献 -300 / -620 ≈ **48%** 的降幅。

### 练习 5（参考答案）

指标 1：**工单总量**——`SELECT COUNT(*) FROM tickets WHERE created_at >= '2026-11-01';`
指标 2：**P1 工单占比**——P1 数 / 总工单数（P1 代表高压力）。
指标 3：**未解决工单数**——`status IN ('open','processing')` 的数量（积压 = 压力）。
指标 4：**工单平均处理时长**——`AVG(resolved_at - created_at)`（效率下降 = 压力）。
指标 5：**工程师人均负载**——按 engineer_id 分组的工单数。

**下结论用哪个**：优先看「未解决工单数」+「P1 占比」的趋势——积压和高优先级同时上升，才说明压力真的变大；单看总量可能只是偶发。
