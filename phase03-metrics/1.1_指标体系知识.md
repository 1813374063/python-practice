# 指标体系知识（阶段 3）

> 目标：把 5 年业务经验显式化成「口径 + 指标 + 分析」能力。
> 这是纯技术候选人给不出的差异化，也是你简历最值钱的部分。

---

## 一、三个必须分清的词

| 词 | 英文 | 是什么 | 例子 |
|---|---|---|---|
| **指标** | Metric | 一个可衡量的**数值** | 门诊量 = 12500 人次 |
| **维度** | Dimension | 切分的**角度** | 按科室、按月份、按工程师 |
| **口径** | Definition | 精确的**计算定义** | 分子是什么、分母是什么、去不去重 |

一句话关系：

> **指标 = 算出来的数；维度 = 从哪个角度看；口径 = 怎么算才算数。**

三者缺一不可：只有指标没有维度 = 看不出问题在哪；只给指标不给口径 = 两个人算出的数不一样，无法对账。

---

## 二、口径是命门（为什么它最重要）

### 案例 1：工单量

同一句「本月工单量 30 条」，至少有 3 种口径：

| 口径 | 定义 | 结果可能不同 |
|---|---|---|
| 按创建时间 | `created_at` 在本月的工单 | 30 |
| 按解决时间 | `resolved_at` 在本月的工单 | 28 |
| 按状态快照 | 当前 status 属于某几类的工单 | 25 |

### 案例 2：工单解决率（最容易吵起来的指标）

| 口径 | 公式 | 谁在用 |
|---|---|---|
| A | `resolved / 总工单` | 只看「标记解决」 |
| B | `(resolved + closed) / 总工单` | 把「已关闭」也算解决 |
| C | `(resolved + closed) / (总工单 - 本月新开)` | 排除在途工单 |

同一个团队，A 算出来 60%，B 算出来 78%，C 算出来 85%。**谁都没算错，只是口径不同。** 所以做报表前第一件事：**把这个指标的口径白纸黑字定下来。**

### 案例 3：接诊量（人次 vs 次数）

- **人次**：同一位患者当天挂两个科室，算 **1 人次**（按人头去重）
- **次数**：同一位患者当天挂两个科室，算 **2 次数**（按就诊记录）

「本月接诊量」到底报哪个？这直接决定数字。你的 `visits` 表用的是「按月、按科室、已汇总的 patient_count」，本身就是一个**已经选定口径**的数据。

## 三、口径三要素（写口径时必写清这三样）

1. **分子 / 分母**：算什么、除以什么
2. **去重规则**：人次 vs 次数、按什么字段去重
3. **时间范围 + 数据源**：按哪个时间字段、取哪张表

写指标的格式建议：

```text
指标名：工单解决率
口径：已解决工单数 + 已关闭工单数 / 当月新建工单总数
去重：按 ticket_id 去重
时间：按 created_at 归属月份
数据源：tickets 表
```

## 四、指标拆解（把大指标拆成能动手的小指标）

### 1. 加法拆解（总量 = 各分项之和）

```text
门诊量 = 内科 + 外科 + 儿科 + 检验科 + ...
```

用途：看「总量下降」是被哪个科室拖累的。

### 2. 乘法拆解（总量 = 因子 × 因子）

```text
收入 = 人次 × 次均费用
工单处理总时长 = 工单量 × 平均处理时长
```

用途：判断是「量」的问题还是「单件效率」的问题。

### 3. 漏斗拆解（转化率）

```text
工单：新建 → 受理 → 处理中 → 解决 → 关闭
门诊：挂号 → 就诊 → 开单 → 缴费 → 取药 g
```

用途：找流失环节。

## 五、分析方法（四板斧）

| 方法 | 怎么用 | 例子 |
|---|---|---|
| **对比** | 同比 / 环比 / 目标比 / 横向比 | 本月门诊量环比下降 8% |
| **趋势** | 看时间序列走向 | 近 4 个月工单量持续上升 |
| **漏斗** | 各环节转化率 | 挂号 1000 → 就诊 850（爽约 15%） |
| **归因** | 贡献度拆解，找主要来源 | 总量下降 5%，其中内科贡献了 4% |

> 归因的关键：不能只说「下降了」，要说出「**哪个科室 / 哪个环节 贡献了多少**」。

---

## 六、分析报告结构（金字塔，结论先行）

```text
1. 结论：本月门诊量下降 8%，主因是内科（贡献 6%）
2. 数据支撑：
   - 总量：12500 → 11500（环比 -8%）
   - 拆解：内科 -6%、外科 -1%、其余 -1%
3. 建议：核查内科 11 月排班/停诊记录；对比去年同期是否季节性
```

**永远先给结论，再给证据，最后给建议。** 不要从「首先我取了一下数据…」开始。

## 七、指标体系怎么写（模板结构）

一份《医院运营指标体系》至少包含这些列：

| 列 | 含义 |
|---|---|
| 分类 | 运营量级 / 效率 / 质量 / 收入 / IT 运维 |
| 指标名 | 如「门诊量」 |
| 口径 | 分子 / 分母 / 去重 / 时间 / 数据源 |
| 公式 | 一句话公式 |
| 维度 | 按科室 / 时间 / 工程师 / 优先级 |
| 时间粒度 | 日 / 月 / 季 |
| 当前值 | 填练习库真实算出来的数 |

> 指标数量：**10–15 个**。宁少勿滥，每个都要能说清口径、能取数。
