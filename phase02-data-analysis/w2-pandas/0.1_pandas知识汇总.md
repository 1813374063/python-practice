## Lesson 1｜DataFrame / Series / 索引 / 布尔筛选 / loc / iloc

### 1. 为什么要有 pandas？

你之前用 for 循环 + 字典手动累加（warmup.py 那 60 行），pandas 把这套活儿**向量化**了：整列一起算，不用一行行写循环。

```text
for 循环思维： 一条一条取出、判断、累加        → 慢、代码长
pandas 思维：  整列一次性筛选、求和、分组      → 快、代码短（用 C 实现）
```

面试常问「向量化为什么快」：因为 pandas/numpy 的底层是 C 写好的批量操作，数据在内存里是连续数组，一次循环跑完；Python 的 for 循环每步都要解释执行，有额外开销。

### 2. 两个核心对象

| 对象 | 长什么样 | 类比 |
|---|---|---|
| `DataFrame` | 二维表格（有行、有列） | 一张 Excel 表 / 数据库的一张表 |
| `Series` | 一列（带索引的一维数组） | 表里的某一列 |

```python
import pandas as pd
df = pd.read_csv("data/workload.csv", encoding="utf-8")  # DataFrame
df["接诊量"]                                              # 取一列 → Series
```

### 3. 认识一张表：`head / info / dtypes / shape`

| 方法 | 作用 |
|---|---|
| `df.head(n)` | 看前 n 行（默认 5） |
| `df.info()` | 看每列类型、非空数量（**查脏数据/缺失值靠它**） |
| `df.dtypes` | 每列的数据类型 |
| `df.shape` | (行数, 列数) |

### 4. 取行取列：`loc` 和 `iloc`

| 写法 | 按什么取 | 例子 |
|---|---|---|
| `df["接诊量"]` | 列名 | 取一整列 |
| `df[["科室", "接诊量"]]` | 多个列名 | 取两列 |
| `df.loc[行标签, 列名]` | 标签（index/列名） | `df.loc[0, "科室"]` |
| `df.iloc[行位置, 列位置]` | 整数位置 | `df.iloc[0, 0]` |

记忆口诀：**`loc` 用「名字」，`iloc` 用「位置」（i = index 数字）。**

### 5. 布尔筛选（最常用，务必熟练）

写一个「条件表达式」返回一列 True/False，再用它筛行：

```python
df["科室"] == "内科"        # → 一列 True/False
df[df["科室"] == "内科"]    # → 只留内科的行
```

多条件用 `&`（与）、`|`（或）、`~`（非），**每个条件都要加括号**：

```python
df[(df["科室"] == "内科") & (df["接诊量"] > 100)]   # 内科且接诊量>100
```

> 注意：是 `&` 不是 `and`（`and` 是 Python 关键字，不能对一列用）。

### 6. 脏数据（本课数据里的「暂无」）

`read_csv` 读到「暂无」时，因为整列是字符串，它会原样留着；你想算数字就得处理。**本课先只识别它，Lesson 2 再正式清洗**：

```python
df["接诊量"].unique()          # 看这一列有哪些不同取值 → 会看到 '暂无'
df[df["接诊量"] == "暂无"]     # 找出脏数据行
```

## Lesson 2｜缺失值与脏数据清洗

### 1. 脏数据是怎么来的

真实数据经常混进非数字（如「暂无」「-」「空」），导致整列被读成**字符串（str）**，无法直接算。

### 2. 识别：`unique` / `isna`

```python
df["接诊量"].unique()          # 看这列有哪些不同取值 → 会发现 '暂无'
df["接诊量"].isna()            # 每一行是不是缺失值（返回 True/False）
df["接诊量"].isna().sum()      # 缺失值个数
```

### 3. 转换：`to_numeric(errors="coerce")`

把一列「尽力转成数字」，转不动的变成 `NaN`（缺失值，Not a Number）：

```python
df["接诊量"] = pd.to_numeric(df["接诊量"], errors="coerce")
```

| errors 取值 | 转不动时 |
|---|---|
| `"coerce"`（最常用） | 变成 `NaN` |
| `"raise"`（默认） | 直接报错 |
| `"ignore"` | 保持原样（等于没转） |

> **坑**：转换后类型是 `float64` 而不是 `int64`，因为 `NaN` 只能存在于小数类型里。整数列一旦有 `NaN` 就会升级成小数。

### 4. 处理缺失值的三种方式

| 方式 | 代码 | 效果 |
|---|---|---|
| 不处理，直接算 | `df["接诊量"].mean()` | 聚合函数**默认自动跳过 NaN**（正好等价于 warmup.py 手动 skip） |
| 删掉 | `df.dropna(subset=["接诊量"])` | 删掉含 NaN 的行 |
| 填充 | `df["接诊量"].fillna(0)` / `.fillna(df["接诊量"].mean())` | 用 0 或平均值填上 |

### 5. 关键洞察（连接 warmup.py）

你 warmup.py 用 `try/except` 手动跳过「暂无」再算平均，写了几十行；pandas 的 `to_numeric(errors="coerce")` + `mean()` 两行就做完了，**因为 mean/sum/max/min 默认忽略 NaN**。

## Lesson 3｜groupby + agg（分组聚合）

### 1. groupby 是什么

「按某列分组，再对每组做计算」，等价于 SQL 的 `GROUP BY`：

```python
df.groupby("科室")["接诊量"].sum()      # 每科总接诊量
df.groupby(["科室", "月份"])["接诊量"].sum()   # 每科每月（多列分组）
```

### 2. 常用聚合函数

| 函数 | 作用 |
|---|---|
| `sum()` | 求和 |
| `mean()` | 平均 |
| `max()` / `min()` | 最大 / 最小 |
| `count()` | 计数（**跳过 NaN**） |
| `median()` | 中位数 |
| `std()` | 标准差 |

### 3. agg 一次算多个指标

```python
df.groupby("科室")["接诊量"].agg(["sum", "mean", "max", "min"])
# 结果是一张表，列名是 sum/mean/max/min
```

### 4. count 和 size 的区别（易错）

```python
df.groupby("科室")["接诊量"].count()   # 跳过 NaN → 有「暂无」的科会是 3
df.groupby("科室").size()              # 数所有行（含 NaN）→ 都是 4
```

> 记住：`count` 数「非空值」，`size` 数「行数」。数据有缺失时两者不同。

### 5. 分组结果常用配套

```python
.reset_index()                # 把分组结果变回普通 DataFrame（去掉索引）
.sort_values("接诊量", ascending=False)   # 按某列排序
```

### 6. 完整模式（连接 warmup.py）

```python
df["接诊量"] = pd.to_numeric(df["接诊量"], errors="coerce")   # 清洗
df.groupby("科室")["接诊量"].agg(["sum", "count", "mean"])    # 分组聚合
```

> 你 warmup.py 里「字典累加 + 计数 + 除」整段，就是上面这一行 `agg(["sum", "count", "mean"])`。

## Lesson 4｜merge（多表关联）+ pivot_table（交叉表）

### 1. merge = SQL 的 JOIN

把两张表按共同列（键）拼成一张：

```python
pd.merge(左表, 右表, on="科室", how="inner")
```

### 2. how 参数（join 类型）

| how | 保留谁 | 类比 |
|---|---|---|
| `"inner"`（默认） | 两表都有的键 | SQL `INNER JOIN` |
| `"left"` | 保留左表全部 | SQL `LEFT JOIN` |
| `"right"` | 保留右表全部 | SQL `RIGHT JOIN` |
| `"outer"` | 两表并集 | SQL `FULL OUTER JOIN` |

> 有「只在一边出现的键」时，另一边的列会填 `NaN`。比如「护理部」只在 departments 里，用 `right/outer` 才会带出来。

### 3. pivot_table = Excel 数据透视表

把「长表」摊成「交叉表」：

```python
df.pivot_table(index="科室", columns="月份", values="接诊量", aggfunc="sum")
```

- `index`：行（分组维度）
- `columns`：列（分组维度）
- `values`：格子里算什么
- `aggfunc`：怎么算（sum/mean/count…）

### 4. pivot_table 的 aggfunc 差异

- `aggfunc="sum"`：全是 NaN 的格子 → `0.0`
- `aggfunc="mean"`：全是 NaN 的格子 → `NaN`

> 这就是为什么同一张交叉表，sum 显示 0、mean 显示 NaN——做报表时要讲清口径，否则「0 接诊量」会被误读成「真的没人来」。

### 5. 交叉表的取值技巧

```python
p.stack().idxmax()   # 找出交叉表里最大值的位置 → ('儿科', '3月')
```
