## 热身（能不看答案写出来 = 过关）

1. 读 CSV 并打印 `shape`，这张表有几行几列？
2. 打印前 3 行（`head(3)`）。
3. 用布尔筛选，找出「外科」的所有行。
4. 用布尔筛选，找出「接诊量大于 120」的所有行。
5. 用 `&` 组合：找出「儿科 且 接诊量 > 130」的行。
6. 用 `loc` 取出第 2 行（index=2）的「月份」；用 `iloc` 取出第 2 行第 2 列。

## 进阶（多想一步）

7. 有多少行是脏数据（接诊量 == "暂无"）？用一句话写出来（提示：`.shape` 或 `len`）。
8. 「接诊量」这一列现在是什么类型？为什么不能直接算平均？
9. 如果只想看「骨科」和「眼科」两科的数据，布尔条件该怎么写？（提示：`isin`）

```python
import pandas as pd
df = pd.read_csv("data/workload.csv", encoding="utf-8")

# 1
print(df.shape)          # (24, 3)

# 2
print(df.head(3))

# 3
print(df[df["科室"] == "外科"])

# 4
print(df[df["接诊量"] > 120])   # 注意：接诊量是字符串，>120 会按字符串比较，本课先照做即可

# 5
print(df[(df["科室"] == "儿科") & (df["接诊量"] > 130)])

# 6
print(df.loc[2, "月份"])   # 3月
print(df.iloc[2, 2])       # 117

# 7
print(df[df["接诊量"] == "暂无"].shape[0])   # 3

# 8
print(df["接诊量"].dtype)   # object（字符串），因为混了「暂无」，不能直接算平均

# 9
print(df[df["科室"].isin(["骨科", "眼科"])])
```
