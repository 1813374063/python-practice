# Lesson 4 练习题（merge + pivot_table）

> 数据：`data/workload.csv`（科室/月份/接诊量）+ `data/departments.csv`（科室/科室编号/门诊楼/床位数，含没数据的「护理部」）
> 做完贴给我改。

## merge 部分

1. 用 `pd.merge(work, depts, on="科室", how="inner")` 内连接，打印行数。
2. 改成 `how="right"`，打印行数，并找出「护理部」那一行的接诊量（是不是 NaN？）。
3. 用 `how="outer"`，打印行数，回答：为什么比 inner 多 1 行？
4. 合并后，打印「门诊楼」这一列有哪些不同的值（去重）。

## pivot_table 部分

5. 用 `pivot_table` 做「科室 × 月份」总接诊量交叉表。
6. 把 `aggfunc` 改成 `"mean"`，看「每科每月平均」交叉表，比较和上一题的区别。
7. 用 `pivot_table` 做「门诊楼 × 月份」的总接诊量（行=门诊楼）。
8. （进阶）交叉表里，哪个「科室-月份」的接诊量最高？（提示：`.max().max()` 或 `.stack().idxmax()`）

```python
import pandas as pd
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent
work = pd.read_csv(BASE_DIR / "data" / "workload.csv", encoding="utf-8")
depts = pd.read_csv(BASE_DIR / "data" / "departments.csv", encoding="utf-8")
work["接诊量"] = pd.to_numeric(work["接诊量"], errors="coerce")

# 1
m = pd.merge(work, depts, on="科室", how="inner")
print(m.shape[0])                 # 24

# 2
r = pd.merge(work, depts, on="科室", how="right")
print(r.shape[0])                 # 25
print(r[r["科室"] == "护理部"])   # 接诊量 = NaN

# 3
o = pd.merge(work, depts, on="科室", how="outer")
print(o.shape[0])                 # 25；护理部只在 depts 里，work 里没有 → 多 1 行

# 4
print(m["门诊楼"].unique())       # ['门诊楼A' '门诊楼B' '门诊楼C']

# 5
p = m.pivot_table(index="科室", columns="月份", values="接诊量", aggfunc="sum")
print(p)

# 6
print(m.pivot_table(index="科室", columns="月份", values="接诊量", aggfunc="mean"))

# 7
print(m.pivot_table(index="门诊楼", columns="月份", values="接诊量", aggfunc="sum"))

# 8
print(p.stack().idxmax())         # ('儿科', '3月')，最高 140
```
