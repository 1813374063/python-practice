## 基础（练「筛选取列」）

1. 读 CSV，打印 `shape`、`dtypes`、前 3 行。
2. 用 `value_counts()` 统计每个科室各有多少行。
3. 接诊量 > 120 的行有多少？（提示：转数字后筛，用 `shape[0]` 或 `len` 计数）
4. 找出「儿科」且「接诊量 > 130」的行，打印整行。
5. 用 `isin` 找出「骨科」「眼科」两科，打印这两科一共几行。

## 进阶（练「索引 + 缺失值 + 计算」）

7. 接诊量 < 90 的科室有哪些？打印去重后的科室名。
8. 分别算 1月、2月、3月、4月 各自的总接诊量。（提示：4 次布尔筛选 + `sum()`）
9. 两种填法对比：分别用 `fillna(0)` 和 `fillna(mean)` 填缺失值，各算一次总接诊量 `sum()`，看差多少。
10. 用 `dropna(subset=["接诊量"])` 删干净后，平均接诊量是多少？和「不删、靠 mean() 自动跳过 NaN」的结果一样吗？

## 思考题（不用写代码，说出答案）

11. 为什么「填 0」会让**平均接诊量变小**，而「填平均值」平均接诊量**不变**？

```python
import pandas as pd
from pathlib import Path

base = Path(__file__).resolve().parent
dps = pd.read_csv(base / "data" / "workload.csv", encoding="utf-8")

# 1
print(dps.shape)      # (24, 3)
print(dps.dtypes)
print(dps.head(3))

# 2
print(dps["科室"].value_counts())   # 每科 4 行

# 3
dps["接诊量"] = pd.to_numeric(dps["接诊量"], errors="coerce")
print(dps[dps["接诊量"] > 120].shape[0])   # 6

# 4
print(dps[(dps["科室"] == "儿科") & (dps["接诊量"] > 130)])   # 3 行

# 5
print(dps[dps["科室"].isin(["骨科", "眼科"])].shape[0])       # 8

# 6
i = dps["接诊量"].idxmax()
print(dps.loc[i])      # 儿科 3月 140

# 7
print(dps[dps["接诊量"] < 90]["科室"].unique())   # ['骨科' '眼科']

# 8
for m in ["1月", "2月", "3月", "4月"]:
    print(m, dps[dps["月份"] == m]["接诊量"].sum())
# 1月 615.0 / 2月 550.0 / 3月 467.0 / 4月 668.0

# 9
print(dps["接诊量"].fillna(0).sum())            # 2300.0（填0不加总）
print(dps["接诊量"].fillna(dps["接诊量"].mean()).sum())   # 2628.57
# 差 328.57 = 3 × 平均(109.52)

# 10
print(dps.dropna(subset=["接诊量"])["接诊量"].mean())  # 109.52
print(dps["接诊量"].mean())                           # 109.52（一样）

# 11 思考题答案：
# 填 0 → 把 3 个「0」也算进平均，把均值拉低；
# 填平均值 → 3 个「109.52」和整体平均一样，不改变均值。
```
