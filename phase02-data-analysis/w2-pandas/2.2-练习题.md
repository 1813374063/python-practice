> 数据：`data/workload.csv`（接诊量列混了 3 个「暂无」）

## 热身

1. 用 `to_numeric(errors="coerce")` 把「接诊量」转成数字，打印新类型。
2. 有多少个缺失值（NaN）？
3. 接诊量的**总接诊量 / 平均值 / 最高 / 最低**各是多少？（一句话分别打印）
4. 用 `dropna` 得到干净数据，打印它的 `shape`。
5. 用 `fillna` 把缺失值填成**该列的平均值**，打印原来那 3 行现在变成了什么。

## 进阶

6. 哪些科室有脏数据？打印这些科室名（去重）。提示：先筛出 `isna()` 的行，再取「科室」列，再用 `.unique()`。
7. `mean()` 自动跳过 NaN，那 `len(df)` 呢？它会计入 NaN 吗？试试 `len(df)` 和 `len(df.dropna(subset=["接诊量"]))` 各是多少，说明区别。

```python
import pandas as pd
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent
df = pd.read_csv(BASE_DIR / "data" / "workload.csv", encoding="utf-8")

# 1
df["接诊量"] = pd.to_numeric(df["接诊量"], errors="coerce")
print(df["接诊量"].dtype)          # float64

# 2
print(df["接诊量"].isna().sum())   # 3

# 3
print(df["接诊量"].sum())          # 2300
print(df["接诊量"].mean())         # 约 109.52
print(df["接诊量"].max())          # 140
print(df["接诊量"].min())          # 76

# 4
print(df.dropna(subset=["接诊量"]).shape)   # (21, 3)

# 5

df_filled["接诊量"] = df_filled["接诊量"].fillna(dps["接诊量"].mean())
print(df_filled[dps["接诊量"].isna()])       # 原来 NaN 的位置变成约 109.52

# 6
print(df[df["接诊量"].isna()]["科室"].unique())   # ['外科' '骨科' '眼科']

# 7
print(len(df))                              # 24（含 NaN 的行也算）
print(len(df.dropna(subset=["接诊量"])))    # 21
# 结论：len 计数所有行，不会跳过 NaN；只有聚合函数（mean/sum/max/min）才跳过 NaN
```
