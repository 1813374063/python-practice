# Lesson 3 练习题（groupby + agg）

> 数据 `data/workload.csv`。开头先 `pd.to_numeric(errors="coerce")` 把接诊量转数字。
> 做完贴给我改。

## 基础

1. 每个科室的总接诊量（`groupby('科室')['接诊量'].sum()`）。
2. 每个科室的平均接诊量（`mean()`）。
3. 用 `agg` 一次算出每科的 `sum / mean / max / min`。
4. 每个科室有几个**有效**接诊量（`count()`，跳过 NaN）？
5. 每个科室有几**行**（`size()`）？和上一题对比，哪几个科室不一样，为什么？
6. 全公司总接诊量是多少（不分科室）？

## 进阶

7. 「科室 × 月份」的总接诊量（多列 `groupby(['科室','月份'])`）。
8. 接诊量**最高**的科室是哪个（用 `sort_values(ascending=False).head(1)`）？
9. 用 `reset_index()` 把第 1 题结果变回普通表，再按总接诊量从高到低排序。
10. 每个科室的「月均接诊量」（提示：`mean()` 自动跳过 NaN，直接 `groupby().mean()` 即可）。

```python
import pandas as pd
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent
df = pd.read_csv(BASE_DIR / "data" / "workload.csv", encoding="utf-8")
df["接诊量"] = pd.to_numeric(df["接诊量"], errors="coerce")

# 1
print(df.groupby("科室")["接诊量"].sum())

# 2
print(df.groupby("科室")["接诊量"].mean())

# 3
print(df.groupby("科室")["接诊量"].agg(["sum", "mean", "max", "min"]))

# 4
print(df.groupby("科室")["接诊量"].count())   # 外科3 骨科3 眼科3，其余4

# 5
print(df.groupby("科室").size())              # 全是 4
# 外科/骨科/眼科 count=3、size=4，因为各有 1 个 NaN

# 6
print(df["接诊量"].sum())                     # 2300.0

# 7
print(df.groupby(["科室", "月份"])["接诊量"].sum())

# 8
print(df.groupby("科室")["接诊量"].sum().sort_values(ascending=False).head(1))

# 9
r = df.groupby("科室")["接诊量"].sum().reset_index()
print(r.sort_values("接诊量", ascending=False))

# 10
print(df.groupby("科室")["接诊量"].mean())
```
