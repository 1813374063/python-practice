## 一、NTILE：把结果均分成 N 份

`NTILE(n)` 把排序后的结果**均分成 n 组**，给每行标桶号 1,2,…,n。

```sql
NTILE(n) OVER (ORDER BY 排序列)
```

规则：
- 能整除：平均分（9 行 ÷ 3 桶 = 每桶 3 行）。
- 不能整除：余数分给**前面的桶**（10 行 ÷ 3 桶 = 3,3,4）。

例子（对应 6.1）：把 9 个科室按工单量分 3 档：

```sql
SELECT dept_id, COUNT(*) AS cnt,
       NTILE(3) OVER (ORDER BY COUNT(*) DESC) AS bucket
FROM tickets
GROUP BY dept_id
ORDER BY cnt DESC;
```

工单量 6,6,5,5,5,3,3,1,1 → 第 1 档是前 3 个（6,6,5），第 2 档中间 3 个，第 3 档最后 3 个。

> 注意：并列的 5（外科/门诊/急诊）谁进第 1 档、谁进第 2 档，取决于数据库的排序，**可能不稳定**。NTILE 只保证"桶数和大致大小"，不保证并列的一定同桶。

## 二、FIRST_VALUE / LAST_VALUE：取首尾值

- `FIRST_VALUE(列)`：窗口内**第一行**的该列值。
- `LAST_VALUE(列)`：窗口内**最后一行**的该列值。

```sql
FIRST_VALUE(created_at) OVER (PARTITION BY dept_id ORDER BY created_at)
```

---

## 三、窗口帧（frame）—— 理解 LAST_VALUE 的坑（重点）

**窗口帧**决定窗口函数"看多宽"。默认帧是：

```text
RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
（从分区第一行 → 当前行）
```

因为默认帧到"当前行"就截止：

- **FIRST_VALUE 不受影响**——帧起点永远是"第一行"，所以它拿到的就是分区第一行的值。
- **LAST_VALUE 出坑**——帧终点是"当前行"，所以 `LAST_VALUE` 默认拿到的是**当前行自己**，不是最后一行！

### 演示（对应 6.4）

```sql
-- ❌ 默认帧：LAST_VALUE 拿到的是"当前行"（等于白算）
SELECT dept_id, ticket_id, created_at,
       LAST_VALUE(created_at) OVER (PARTITION BY dept_id ORDER BY created_at) AS wrong_last
FROM tickets
ORDER BY dept_id, created_at;

-- ✅ 显式写全窗口帧：从分区第一行到最后一行
SELECT dept_id, ticket_id, created_at,
       LAST_VALUE(created_at) OVER (PARTITION BY dept_id ORDER BY created_at
           ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING) AS right_last
FROM tickets
ORDER BY dept_id, created_at;
```

跑一下对比两列：内科那 6 行里，`wrong_last` 每行 = 自己的 created_at；`right_last` 每行 = 内科最晚那张工单的 created_at。

> 记忆口诀：**FIRST 默认对，LAST 要加"全窗口帧"。**

## 四、无分区窗口 OVER()：全局计算

`OVER()` 里什么都不写 = 把**整个结果集当成一个窗口**，算全局值：

```sql
MAX(cnt) OVER ()   -- 全局最大值（每行都一样）
SUM(cnt) OVER ()   -- 全局总和（算占比）
AVG(cnt) OVER ()   -- 全局平均
```

例子（对应 6.6 + 6.7）：

```sql
SELECT dept_id, COUNT(*) AS cnt,
       MAX(COUNT(*)) OVER () AS global_max,
       ROUND(COUNT(*)::numeric / SUM(COUNT(*)) OVER () * 100, 2) AS pct
FROM tickets
GROUP BY dept_id
ORDER BY dept_id;
```

- `global_max`：每行都是 6（全局工单量最多的科室）。
- `pct`：每行 = 该科室工单数 ÷ 35 × 100（占比）。

## 六、易混淆点

```text
NTILE 分桶"大小大致相等"，不保证并列同桶
FIRST_VALUE 默认就对，LAST_VALUE 默认拿的是"当前行"
无分区 OVER() = 全局一个窗口，算最大值/总和/平均
窗口帧 ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING = 看全分区
```
