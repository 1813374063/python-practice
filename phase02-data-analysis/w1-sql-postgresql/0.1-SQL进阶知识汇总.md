## 专业名词汇总

### 1. JOIN

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| 内连接 INNER JOIN | 只保留两边都能匹配上的行。 | 匹配不上的行会被丢掉。 |
| 左连接 LEFT JOIN | 保留左表全部行，右表匹配不上填 NULL。 | "没有工单的科室"要用 LEFT JOIN + IS NULL。 |
| 右连接 RIGHT JOIN | 与左连接方向相反，保留右表全部行。 | 实际中少用，通常用 LEFT JOIN 换顺序即可。 |
| 全连接 FULL JOIN | 两边都保留，匹配不上填 NULL。 | 场景少见，别和 UNION 混淆。 |
| 笛卡尔积 | 两边不做条件直接连接，行数相乘。 | JOIN 漏写 ON 条件就会产生。 |

### 2. 子查询

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| 子查询 | 嵌在另一个查询里的查询。 | 可放 WHERE、FROM、SELECT 等位置。 |
| 标量子查询 | 返回单个值的子查询。 | 必须只返回一行一列。 |
| EXISTS | 判断子查询是否至少返回一行。 | 通常比 IN 更高效，尤其子查询结果大时。 |
| IN | 判断值是否在子查询结果集合里。 | 子查询含 NULL 时结果可能意外。 |

### 3. 聚合与分组

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| GROUP BY | 按指定字段分组后聚合。 | SELECT 里非聚合字段必须出现在 GROUP BY。 |
| HAVING | 对分组结果再过滤。 | 写在 GROUP BY 之后；WHERE 是分组前过滤。 |
| COUNT(*) | 数行数。 | 与 COUNT(字段) 不同——后者不数 NULL。 |
| DISTINCT | 去重。 | 与 GROUP BY 去重效果相近，但语义不同。 |

### 4. 窗口函数

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| 窗口函数 | 在"某个分区窗口"内逐行计算，不合并行。 | 与 GROUP BY 不同，不减少结果行数。 |
| PARTITION BY | 定义窗口分区（类似分组）。 | 只影响窗口，不影响结果行数。 |
| ROW_NUMBER | 每行分配唯一连续编号。 | 并列也会给不同编号。 |
| RANK | 排名，并列同名次且跳过后续名次。 | 1,2,2,4 是 RANK；1,2,2,3 是 DENSE_RANK。 |
| LAG / LEAD | 取当前行之前/之后某行的值。 | 常用于算环比、同比。 |
| 累计值 SUM OVER | 窗口内按顺序累加。 | 加 ORDER BY 才是累计，不加是分区总和。 |

### 5. CTE 与口径

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| CTE（WITH） | 用 WITH 给子查询起名，方便复用和拆解。 | 只是可读性工具，不改变查询结果。 |
| 指标口径 | 一个指标的统一定义（单位、去重、时间范围）。 | 口径不定，同一指标可算出不同结果。 |
| 环比 | 与上一期比较的增长率。 | 用 LAG 取上期值再相除。 |
| 闭开区间 | 时间过滤 `>= 月初 AND < 下月初`。 | 避免漏掉/重复边界时刻的记录。 |
| 量纲 | 指标的单位和性质（件 / 人次 / 元）。 | 不同量纲的指标不能直接相加比较。 |
