# 阶段 1 SQL 进阶 —— 练习题

> 配套数据：第一次先运行 `1.0-create_db.sql` 一键建库；想重置数据时再运行 `1.1-init_db.sql`。
> 四个表：`departments`（科室）、`engineers`（工程师）、`tickets`（工单）、`visits`（月度接诊量）。
> 做题顺序：A 基础复习 → B JOIN → C 子查询 → D 窗口函数 → E CTE 与口径。
> 每题先自己写，写完对照文末「参考答案」。

---

## Part A｜基础复习（你的 pgsql 舒适区，先热手）

| 题号 | 题目 | 考点 |
|---|---|---|
| A1 | 查出所有科室的名称和类别，按 `dept_id` 升序排列 | SELECT / ORDER BY |
| A2 | 统计每个科室的工单数量，按数量降序 | GROUP BY + COUNT |
| A3 | 找出 2026 年 10 月创建的工单（注意日期口径用「闭开区间」） | WHERE + 日期范围 |
| A4 | 各优先级（P1/P2/P3）的工单分别有多少 | GROUP BY priority |
| A5 | 已解决工单（resolved / closed）的平均处理天数 | 日期相减 + 口径 |

**通过标准**：A3 结果是 5 条；A5 你能说清"处理天数 = resolved_at − created_at，口径是整天还是小时"。

## Part B｜JOIN（本周重点）

| 题号 | 题目 | 考点 |
|---|---|---|
| B1 | 列出每张工单的科室名称、类别、优先级、状态 | 内连接 |
| B2 | 找出**没有任何工单**的科室 | LEFT JOIN + IS NULL / NOT EXISTS |
| B3 | 每个科室的工单数，**包含 0 工单的科室**（共 9 行） | LEFT JOIN + COUNT(字段) 而非 COUNT(*) |
| B4 | 每个工程师处理的工单数，**包含没处理过工单的工程师** | engineers LEFT JOIN tickets |

**通过标准**：B3 里放射科=0、护理部=0；B4 里赵敏=0；能说清「为什么这里必须用 `COUNT(t.ticket_id)` 而不是 `COUNT(*)`」。

## Part C｜子查询 / EXISTS

| 题号 | 题目 | 考点 |
|---|---|---|
| C1 | 找出工单数量最多的科室（并列也要都列出来） | 子查询 + MAX / HAVING |
| C2 | 找出「有 P1 工单」的科室名称 | EXISTS / IN |
| C3 | 找出工单数量**高于所有科室平均值**的科室 | 子查询 AVG |

**通过标准**：C1 结果是「内科」；C3 结果 5 个科室；能解释 EXISTS 和 IN 的适用区别。

## Part D｜窗口函数（本周最难，值得反复练）

| 题号 | 题目 | 考点 |
|---|---|---|
| D1 | 给每个科室的工单按创建时间从早到晚编号（每科内部 1,2,3…） | ROW_NUMBER + PARTITION BY |
| D2 | 各科室按工单量排名，并列同名次（第 1、2、2、4…） | RANK |
| D3 | 内科每个月的接诊量，以及**环比增长率**（本月比上月增长 %） | LAG |
| D4 | 每个科室接诊量的**累计值**（按时间累积） | SUM OVER + PARTITION BY |

**通过标准**：D3 里 10→11 月内科环比约 −25.4%；D4 内科累计到 11 月 = 4510；能解释 ROW_NUMBER 和 RANK 的区别。

## Part E｜CTE 与指标口径

| 题号 | 题目 | 考点 |
|---|---|---|
| E1 | 用 `WITH`（CTE）拆解：算出各科室**月均接诊量**，列出 Top 3 | WITH + GROUP BY + ORDER BY + LIMIT |
| E2 | 口径讨论题（写文字，不写 SQL）：同一个月的「工单量」和「接诊量」有没有可比性？如果领导要一张"科室运营总览"，你会怎么定义每列的指标口径？ | 指标口径 / 业务判断 |

**通过标准**：E1 结果顺序是 门诊部 → 急诊科 → 检验科；E2 你能说出「工单量是问题事件数，接诊量是服务人次，两者量纲不同，不能直接相加比较，应按科室分别展示」。

## 参考答案

> 参考答案里 `COUNT(t.ticket_id)`、日期「闭开区间」、`RANK` 这些细节，正是面试会追问的点。

### Part A

```sql
-- A1
SELECT dept_id, dept_name, category
FROM departments
ORDER BY dept_id;

-- A2
SELECT dept_id, COUNT(*) AS ticket_cnt
FROM tickets
GROUP BY dept_id
ORDER BY ticket_cnt DESC;

-- A3（闭开区间：>= 10月1日 且 < 11月1日）
SELECT * FROM tickets
WHERE created_at >= '2026-10-01' AND created_at < '2026-11-01';

-- A4
SELECT priority, COUNT(*) AS cnt
FROM tickets
GROUP BY priority
ORDER BY priority;

-- A5
SELECT AVG(resolved_at - created_at) AS avg_days
FROM tickets
WHERE status IN ('resolved', 'closed');
```

### Part B

```sql
-- B1
SELECT t.ticket_id, d.dept_name, d.category, t.priority, t.status
FROM tickets t
JOIN departments d ON d.dept_id = t.dept_id
ORDER BY t.ticket_id;

-- B2（两种写法）
SELECT d.dept_name
FROM departments d
LEFT JOIN tickets t ON t.dept_id = d.dept_id
WHERE t.ticket_id IS NULL;

SELECT dept_name FROM departments d
WHERE NOT EXISTS (SELECT 1 FROM tickets t WHERE t.dept_id = d.dept_id);

-- B3（关键：COUNT(t.ticket_id)，不能 COUNT(*)）
SELECT d.dept_name, COUNT(t.ticket_id) AS ticket_cnt
FROM departments d
LEFT JOIN tickets t ON t.dept_id = d.dept_id
GROUP BY d.dept_id, d.dept_name
ORDER BY ticket_cnt DESC, d.dept_name;

-- B4
SELECT e.name, COUNT(t.ticket_id) AS handled_cnt
FROM engineers e
LEFT JOIN tickets t ON t.engineer_id = e.engineer_id
GROUP BY e.engineer_id, e.name
ORDER BY handled_cnt DESC;
```

### Part C

```sql
-- C1（并列都要出来）
SELECT d.dept_name
FROM departments d
WHERE d.dept_id IN (
    SELECT dept_id FROM tickets GROUP BY dept_id
    HAVING COUNT(*) = (
        SELECT COUNT(*) FROM tickets GROUP BY dept_id ORDER BY COUNT(*) DESC LIMIT 1
    )
);

-- C2
SELECT dept_name FROM departments d
WHERE EXISTS (
    SELECT 1 FROM tickets t WHERE t.dept_id = d.dept_id AND t.priority = 'P1'
);

-- C3
SELECT dept_id, COUNT(*) AS cnt
FROM tickets
GROUP BY dept_id
HAVING COUNT(*) > (
    SELECT AVG(c) FROM (SELECT COUNT(*) AS c FROM tickets GROUP BY dept_id) sub
);
```

### Part D

```sql
-- D1
SELECT dept_id, ticket_id, created_at,
       ROW_NUMBER() OVER (PARTITION BY dept_id ORDER BY created_at) AS rn
FROM tickets;

-- D2
SELECT dept_id, COUNT(*) AS cnt,
       RANK() OVER (ORDER BY COUNT(*) DESC) AS rk
FROM tickets
GROUP BY dept_id;

-- D3（环比增长率）
SELECT visit_month, patient_count,
       LAG(patient_count) OVER (ORDER BY visit_month) AS prev_count,
       ROUND(
         (patient_count - LAG(patient_count) OVER (ORDER BY visit_month))::numeric
         / LAG(patient_count) OVER (ORDER BY visit_month) * 100, 2
       ) AS pct_change
FROM visits
WHERE dept_id = 1
ORDER BY visit_month;

-- D4（累计）
SELECT dept_id, visit_month, patient_count,
       SUM(patient_count) OVER (PARTITION BY dept_id ORDER BY visit_month) AS running_total
FROM visits
ORDER BY dept_id, visit_month;
```

### Part E

```sql
-- E1
WITH dept_monthly AS (
    SELECT dept_id, ROUND(AVG(patient_count)) AS avg_visits
    FROM visits
    GROUP BY dept_id
)
SELECT d.dept_name, dm.avg_visits
FROM dept_monthly dm
JOIN departments d ON d.dept_id = dm.dept_id
ORDER BY dm.avg_visits DESC
LIMIT 3;

-- E2（文字题，参考要点）
-- 工单量 = 问题事件数（量纲：件），接诊量 = 服务人次（量纲：人次），不可直接相加比较。
-- 「科室运营总览」应分列展示：接诊量、工单量、工单占比、P1 数、平均处理时长，各列各自有口径。
```
