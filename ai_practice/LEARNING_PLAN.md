### 1.3 六个"看起来会了、其实还欠一层"的地方

这是复习阶段要逐个拆掉的靶子，也是面试官最爱追问的点。

**① 8/8 准确率是虚高的（最重要）**

`4.2-prompt_eval_results.json` 显示 8 条全对，`category_accuracy = 1.0`。但对比 `EXAMPLES` 和 `TEST_CASES`：

- `TEST_CASES[0]`「门诊叫号大屏黑屏，但诊室电脑和叫号声音正常。」与 `EXAMPLES[0]` **一字不差**
- `TEST_CASES[3]`「护理部要求新增三个护理记录导出字段」与 `EXAMPLES[2]`「护士希望新增护理记录批量导出字段」是同一模板换词

8 条里至少 2 条是"背过答案的"。你自己的名词表里写了"数据泄漏 → 结果虚高"，但代码里正好踩了这一条。**这是全篇最值得重做的实验。**

**② RAG 检索没有相关性阈值**

`2.3-rag_retrieval_results.json` 里，第一个问题的第三个召回 `KB-003` 得分只有 **1 分**（仅"医生"一词命中），却照样进了 `top_k=3`、照样塞进提示词。你已经在 lesson05 名词表里写了"相关性阈值"，但 lesson04 的代码里没实现。低分噪声进上下文，是 RAG 答非所问的头号原因。

**③ 语义检索停在"手写向量"**

lesson05 的 `[0.90, 0.10, 0.05]` 是人编的示意值，不是 Embedding 模型输出。余弦相似度的公式你会写了，但"文本 → 向量"这一步没走通，向量库、增量索引、召回率评估也都还只是名词。

**④ `history` 无限增长**

`1.1-chat.py` 每轮都 `append`，没有截断、没有摘要、没有 token 预算。名词表里你会解释"上下文窗口"，但代码里没有任何处理——聊 30 轮就会超限报错。面试问"长对话怎么优化"，这里就是标准答案的落点。

**⑤ SQL 和 pandas 停在入门**

SQL 只用到 `GROUP BY` + `SUM`，没有 JOIN、没有窗口函数（`ROW_NUMBER`/`LAG`，算同比环比必备）、没有 CTE。数据处理全靠 `for` 循环 + 字典累加（`warmup.py` 里 `sums`/`counts` 两个字典手动维护），这是 pandas 一句话的事。**数据分析岗考的就是这一层。**

**⑥ 缺工程习惯与交付物**

没有 `venv` 和 `requirements.txt`（全局装了 `openai`，pandas 至今没装，我这边已验证：`ModuleNotFoundError: No module named 'pandas'`）；没有 README；没有单元测试；代码只能自己电脑上跑。作品集需要"别人 clone 下来能跑"。

## 3. 复习计划（W1–W2，约 20 小时）

### 3.1 原则：不要重读，要"改造"

你已经写过一遍知识汇总了，再看一遍收益很低。复习只做三件事：

```text
第 1 遍（30 分钟 / 课）：遮住"容易混淆点"列，自己口述解释，说不出来才翻
第 2 遍（60 分钟 / 课）：改一个参数、跑一次、对比结果 —— 把"知道"变成"会用"
第 3 遍（15 分钟 / 课）：用面试官口径自问自答，录音听完挑毛病
```

**为什么第 2 遍最重要：** 你现在掌握的很多是"名词级"知识（例如"阈值"、"重排序"、"数据泄漏"）。面试官一问"你实际怎么设阈值的"就会露馅。改一次参数、看一眼结果变化，这个知识才变成你的。
