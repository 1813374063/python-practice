# 第 4 课文件导航

本文件只用于说明每个文件的用途、输入、输出和阅读顺序，不参与程序运行。

## 文件清单

| 文件 | 类型 | 主要用途 | 输入 | 输出 | 调用模型 |
|---|---|---|---|---|---|
| `0.1-CODE_READING_NOTES.md` | 笔记 | 说明代码阅读目标和核心调用关系 | 无 | 阅读说明 | 否 |
| `0.2-文件导航.md` | 笔记 | 说明本课每个文件的作用和阅读顺序 | 无 | 文件用途说明 | 否 |
| `1.1-rag_knowledge.json` | 资料 | 保存虚构医院信息科知识资料 | 无 | 8 条知识文档 | 否 |
| `1.2-chunking_demo.py` | 代码 | 按章节切分长制度文本 | 内置制度文本 | `1.3-chunks.json` | 否 |
| `1.3-chunks.json` | 结果 | 保存切分后的片段和元数据 | 由 `1.2` 生成 | 5 个片段 | 否 |
| `2.1-retrieval_common.py` | 代码 | 提供关键词提取、评分、排序和提示词组装函数 | 知识文档和问题 | Python 函数 | 否 |
| `2.2-rag_retrieval.py` | 代码 | 批量测试 5 个问题的本地检索效果 | `1.1-rag_knowledge.json` | `2.3-rag_retrieval_results.json` | 否 |
| `2.3-rag_retrieval_results.json` | 结果 | 保存关键词、召回资料和检索分数 | 由 `2.2` 生成 | 5 组检索结果 | 否 |
| `3.1-grounded_prompt_preview.json` | 结果 | 保存最终准备发送给模型的 system 和 user 消息 | 问题和召回资料 | 完整 `messages` | 否 |
| `4.1-grounded_answer_demo.py` | 代码 | 默认预览提示词；加 `--call` 才调用一次模型 | 问题、召回资料、公共检索模块 | 预览 JSON 或回答 JSON | 仅 `--call` 时调用 |
| `4.2-grounded_answer_smoke.json` | 结果 | 未来执行 `4.1 ... --call` 后保存模型回答和 token | 由 `4.1 --call` 生成 | 回答、来源和用量 | 仅后续生成 |

## 阅读时只需要回答

1. 这个文件是代码、资料还是运行结果？
2. 它从哪里读取输入？
3. 它产生什么输出？
4. 它是否调用模型？
5. 它在整个 RAG 流程中的位置是什么？

当前不要求逐行理解所有 Python 语法。
