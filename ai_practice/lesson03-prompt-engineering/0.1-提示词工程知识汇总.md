## 专业名词汇总

### 1. 角色设定

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| Prompt | 发送给模型的任务说明、规则和上下文。 | Prompt 不只等于用户一句话。 |
| 提示词工程 | 通过规则、示例和输出格式持续改进模型结果。 | 它不是一次写完就结束，需要测试和迭代。 |
| 角色提示词 | 说明模型应以什么身份、目标、约束和格式工作。 | 只说“你是专家”通常约束不足。 |
| 软约束 | 通过提示词要求模型遵守的规则。 | 它不等于权限控制或安全边界。 |

### 2. 结构化输出

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| 结构化输出 | 让模型返回字段固定、程序可读取的数据。 | 结构化不等于业务结论必然正确。 |
| JSON | 用对象、数组、字符串、数字和布尔值表示数据。 | JSON 对象解析后是 Python 字典。 |
| JSON Output | 通过接口参数要求模型生成合法 JSON。 | 只保证语法，不保证字段和业务含义。 |
| `response_format` | 指定文本或 JSON 输出格式的请求参数。 | 开启 JSON 模式仍需提示词说明结构。 |
| JSON Schema | 描述 JSON 字段、类型和约束的规则。 | Schema 描述结构，不负责判断业务真实性。 |
| `json.loads()` | JSON 字符串转 Python 数据。 | 对象转字典，数组转列表。 |
| `json.dumps()` | Python 数据转 JSON 字符串。 | 与 `loads` 方向相反。 |
| `max_tokens` | 限制本次生成阶段最多使用的 token。 | 可能包含推理 token，过低会使正文为空。 |
| 推理 token | 模型内部思考阶段消耗的 token。 | 不等于最终可见正文。 |
| `finish_reason` | 模型停止生成的原因。 | `stop` 正常结束，`length` 达到上限。 |
| `temperature` | 控制采样随机倾向的参数。 | DeepSeek thinking mode 下没有效果。 |
| Thinking mode | 模型先进行内部推理再输出正文的模式。 | 会增加推理 token 消耗。 |
| `usage` | 接口返回的 token 统计。 | 总公式为 prompt 加 completion。 |
| Prompt Cache | 复用相同请求前缀的缓存。 | 前缀变化可能导致缓存未命中。 |

### 3. Few-shot 少样本示例

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| Zero-shot | 不给示例直接完成任务。 | 没有示例不代表没有规则。 |
| One-shot | 给一个输入输出示例。 | 一个示例不一定覆盖所有边界。 |
| Few-shot | 给少量示例引导输出模式。 | 它不是训练或微调，不修改模型参数。 |
| 示例对 | 一组 user 输入和 assistant 标准输出。 | 只有 assistant 答案时模型不知道对应问题。 |
| In-context Learning | 模型在上下文中根据示例完成任务。 | 当前请求结束后，这些示例不会进入模型参数。 |

### 4. 评估与接口

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| 测试集 | 用于检查提示词或系统效果的一组样例。 | 训练或示例中出现的样例不应直接作为独立测试集。 |
| 数据泄漏 | 测试样例与示例高度重合，导致结果虚高。 | 高准确率不一定代表真实泛化能力。 |
| Smoke 测试 | 用一条代表性样例快速检查基本流程。 | 它不能证明整体准确率。 |
| Fast 测试 | 用少量代表性样例覆盖主要类别。 | 它适合快速迭代，不等于完整评估。 |
| Full 测试 | 对完整测试集运行。 | 需控制 token 和学习成本。 |
| 分类准确率 | 分类正确数量占总样例的比例。 | 小样本上的准确率不能直接外推生产环境。 |
| 业务复核 | 由业务人员检查回答是否符合真实制度。 | 不能只依赖程序校验。 |

### 5. 接口请求与响应

| 名词 | 一句话解释 | 容易混淆点 |
|---|---|---|
| `model` | 指定使用的模型。 | 模型名称必须与平台支持列表一致。 |
| `messages` | 请求中的消息列表。 | 包含系统规则、历史、示例和当前问题。 |
| `choices[0]` | 响应中的第一个候选回答。 | 列表从 0 开始计数。 |
| `message.content` | 候选回答的可见正文。 | 与 token 用量不是一回事。 |
| `prompt_tokens` | 输入内容消耗的 token。 | 包含 system、示例和用户问题。 |
| `completion_tokens` | 生成阶段消耗的总 token。 | 可能包含推理 token。 |
| `total_tokens` | 请求总 token。 | 等于 prompt 加 completion。 |
